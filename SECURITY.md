# Security Policy

Please report suspected vulnerabilities privately through this repository's
GitHub Security Advisories page:

`https://github.com/devibeee/smart-distribution-program/security/advisories/new`

Include the affected program ID, instruction, transaction signature or minimal
reproduction, expected impact, and any suggested remediation. Do not disclose
an unpatched vulnerability publicly before the maintainer has had a reasonable
opportunity to investigate and publish a fix.

No auditor or release signature is claimed unless the corresponding public
evidence exists for that release.
